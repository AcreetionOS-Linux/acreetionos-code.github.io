Daily AcreetionOS Update -- August 27, 2026

August 27, 2026

Yesterday’s CI fix for the release workflow in acreetionos-immutable got the automated ISO builds back on track after a YAML indentation hiccup stalled the nightly release. The adjustment to pass -R to gh release create removed the unnecessary checkout step, and the corrected block‑scalar indentation in release.yml quieted the validation errors that had been blocking merges. This means the project can once again push fresh ISOs to the download page without manual intervention, keeping the release cadence smooth for everyone tracking the changelog.

Development Besides the workflow rescue, the intelligence sync commit added updated newsletter templates, archive entries, and wiki guides to acreetionos-code.github.io, ensuring the documentation mirrors the latest site changes. Meanwhile, acreetionos-code-acreetionos gained an explicit ShellCheck lint step on its top‑level scripts, catching a few stray syntax issues before they reach main. Over in acreetionos-plasma, a new welcome workflow now runs on first‑time contributor pull requests, and ShellCheck linting was added there as well, reinforcing code quality across the Plasma spin.

Community Outside the repo, Armbian 26.8 dropped yesterday, bringing refreshed kernel packages and improved board support for a range of ARM devices—worth a look if you run AcreetionOS on anything like a Raspberry Pi or Pine64. Alongside that, the usual mid‑week security updates arrived from AlmaLinux and Debian, covering Firefox, GStreamer, the kernel, and several libraries; upgrading those packages keeps your system hardened against the latest CVEs. The project’s Discord remains the best place to chat about these updates or to ask for help testing the new ISOs.

Tip of the day If you’re maintaining your own scripts, run shellcheck -x script.sh locally before pushing; the CI will thank you, and you’ll catch quirks like missing quotes or unintended glob expansions early. For a quick check, you can also add #!/usr/bin/env bash at the top and let the lint step in acreetionos-code-acreetionos do the heavy lifting, keeping your contributions clean and the build green.

Stay tuned for the next ISO spin—head over to https://acreetionos.org/flash.html to grab the latest build, and review the full details at https://acreetionos.org/changelog.html. Happy hacking!
