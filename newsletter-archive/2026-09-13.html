Daily AcreetionOS Update -- September 13, 2026

September 13, 2026

geocode-glib conflict resolved in acreetionos and acreetionos-xlibre

The geocode-glib update quietly broke things on installed AcreetionOS systems this week, and the team responded fast, merging a dedicated repair branch before it snowballed. If you have been seeing geocode-related errors after a routine update, this fix is for you.

Development

The calamares-config repo saw two practical improvements this cycle. A commit now prefers 1080p gfxmode over native 4K during boot, which should spare older hardware from unnecessary resolution negotiation. Another change fixed NVIDIA compatibility for older GPUs and removed disk encryption from the default installer flow, letting users add it later if they want it. On the CI side, both Natalie and Darren locked down secret detection and SAST scanning in their GitLab pipelines this week.

Community

EuroPython 2026 videos are now published, covering the Krakow conference from July 13 through its follow-up dates, so if you missed the talks you can catch up on the recordings. On the kernel front, Greg Kroah-Hartman shipped stable updates for both 7.2.5 and 6.18.51 this Friday. Security advisories from AlmaLinux, Debian, and Fedora also dropped, touching everything from bluez to ruby-rack.

Tip of the day

Want to check whether your system already has the geocode-glib fix? Run pacman -Q geocode-glib and compare against the versions listed on the changelog at acreetionos.org/changelog.html. If you are running an older install, the repair branch details are documented in the project wiki at acreetionos.org/wiki.html.
