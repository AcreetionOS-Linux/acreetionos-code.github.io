Daily AcreetionOS Update -- August 31, 2026

August 31, 2026

AcreetionOS installer now prefers 1080p over native 4K on boot for smoother graphics output

If you've been wrestling with black screens or choppy boot graphics on high-DPI displays, Darren (cobra3282000) pushed a fix today that should help. The Calamares config now explicitly prefers 1080p gfxmode over native 4K, which means the boot screen and installer should render more reliably on systems where the GPU stumbles at ultra-high resolutions. It's a small change, but it directly impacts that critical first impression when someone flashes AcreetionOS and boots up.

DEVELOPMENT

The geocode-glib package update conflict has been resolved. Users with existing AcreetionOS installations were hitting a package conflict during system updates. The repair branch has been merged, and the fix is live. If you're on an installed system, a full system upgrade should now complete cleanly. Check the changelog at https://acreetionos.org/changelog.html for the full list of what's been patched.

On the infrastructure side, Natalie (natalie) has been hardening CI pipelines across personal projects with secret detection and SAST scanning configured in .gitlab-ci.yml files. This behind-the-scenes work keeps the project's development practices solid even when the spotlight isn't on it.

Darren also removed forced disk encryption from the default ISO installer config, noting that users who want it can add it post-install. This streamlines the out-of-box experience for the majority of users while keeping encryption available for those who need it.

COMMUNITY

The broader Linux world had a busy week. Linus released kernel prepatch 7.3-rc1, closing the merge window for that cycle. Meanwhile, Debian voted to allow "responsible use of generative AI" in official Debian work—a decision that will likely ripple across the ecosystem. Konstantin Ryabitsev also published hard data on AI crawler impact on kernel.org, showing just how aggressive automated scraping has become.

TIP OF THE DAY

If you're experiencing display issues during boot or install, try pressing 'e' at the GRUB menu and adding "video=1080p" to the kernel line. With today's Calamares update prioritizing 1080p, this should match the expected behavior and get you through to a clean desktop. More troubleshooting tips are in the wiki at https://acreetionos.org/wiki.html.

Download the latest build at https://acreetionos.org/flash.html.
